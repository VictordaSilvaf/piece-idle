# Assets do MVP

Coloque os arquivos recebidos nestas pastas para a próxima integração visual:

- `characters/` — spritesheets ou PNGs dos personagens.
- `enemies/` — spritesheets ou PNGs de inimigos.
- `tiles/` — tilesets, cenário de porto e ilhas.
- `ui/` — ícones, molduras e elementos de interface.

Formatos preferidos: PNG ou WebP com fundo transparente para personagens e inimigos; PNG para tilesets. Quando os arquivos estiverem aqui, o canvas substituirá os ícones temporários por sprites reais.
